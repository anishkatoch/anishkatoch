## 🔥 Featured Project

### [ARIA](https://github.com/anishkatoch) — Lumen Agent AI Search Engine
An intelligent agent framework combining a **Lumen Agent AI search engine**, **script intelligence**, and a **voice agent** into one system — enabling natural-language search, automated script understanding/generation, and real-time voice interaction.

- 🔎 **AI Search Engine** — semantic + agentic retrieval over documents and the web (RAG pipeline)
- 🧠 **Script Intelligence** — parses, understands, and generates scripts/code with contextual reasoning
- 🎙️ **Voice Agent** — speech-to-text, LLM reasoning, and text-to-speech for hands-free interaction
- 🤖 Built as a multi-agent system with tool use, memory, and orchestration
